# subplace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI that reads a saved CR job project, places every DX/FN caption cue at its SOP spot or the nearest spot clear of burned-in text, and writes `vN+1` with every cue already styled (from Morgan's `.prtextstyle` files) and positioned, plus an HTML report.

**Architecture:** Pure-Python package in the cr-premiere-versioning skill folder. Pipeline: read cues from the project → label, gloss and vendor-move flag → OCR detections on the master → placement search → write new FlatBuffer cue blobs into a copy of the project → decode-back check → report. Premiere is never touched while it has the project open. Frame verification and calibration renders go through the Premiere MCP, driven by the operator (Claude) following SKILL.md.

**Tech Stack:** Python 3.13, pytest, numpy, Pillow, easyocr (CRAFT, via media-qc `textdetect.py`), ffmpeg/ffprobe on PATH.

**Spec:** `docs/superpowers/specs/2026-10-07-subplace-design.md` (approved 2026-10-07; open questions accepted at defaults).

## Global Constraints

- Code root: `~/.claude/skills/cr-premiere-versioning/scripts/subplace/` (symlinked into `~/Documents/Projects/claude-dotfiles`). Commit there; push only as `morganms313`.
- Tests: `cd ~/.claude/skills/cr-premiere-versioning/scripts && python3 -m pytest subplace/tests -q`. Tests that need Lucid or OCR are marked `@pytest.mark.slow` and skip when inputs are missing.
- Style source of truth: `.prtextstyle` files, canonical copy at `~/.claude/skills/cr-premiere-versioning/references/CR-styles/` (copied from `~/Desktop/caption_ext_test/CR-styles/`, all 17 files).
- Defaults (Morgan accepted): title safe **5%** of width and of height on each side; minimum gap to detected text **12 px**; report written locally to `--out`.
- Search steps **8 px** vertical, **80 px** horizontal; cost `|dy| + 1.5·|dx|`. A timing trim is suggested only if it leaves **≥ 1.0 s** of display.
- Never modify cue text; never write into a project file that is the input (`--project`) — output is always a new `vN+1` path (`_MS_v2` → `_MS_v3`).
- Fail loudly and write nothing on: missing style combination, styled caption track (`<ParentStyle>`), unknown blob field, unmatched project cue, frame-count mismatch between master and sequence.
- Ticks per second in `.prproj`: **254016000000**. Sequence fps from the CLI (`--fps`, default 23.976).
- Caption track convention: first caption track = **DX (CC1)**, second = **FN (CC2)**. Overridable with `--dx-track` and `--fn-track`.

## Review Focus

1. **Shared blobs.** Most caption blocks are `<FormattedTextData … BinaryHash="X"/>` with no content, pointing by hash at the one block that holds X. Expected: the writer gives each target cue its own content-bearing block with a fresh hash, and every other block, including the original holder of X, decodes exactly as before. → Task 6 `test_shared_hash_holders_untouched`.
2. **The project has fewer cues than the vendor files** (it-IT FN: 5 vendor cues, 4 in the project, title dropped). Expected: the extra vendor cue is listed as "not in project", there's no error, and every project cue is still placed. → Task 3 `test_vendor_cue_missing_from_project_is_reported`.
3. **Cue timing was trimmed in the project** after a revision (e.g. it-IT 10/7 end-time trims). Expected: matching to the `.ass` still succeeds on text plus nearest start, with a ±12-frame tolerance. → Task 3 `test_match_survives_trimmed_end`.
4. **Inline italics** (multi-run cue). Expected: the whole cue is written in the first run's style and flagged `MULTI_RUN`, without crashing or losing text. → Task 6 `test_multi_run_cue_flagged_text_kept`.
5. **The output path already exists** (`vN+1` saved earlier). Expected: refuse unless `--overwrite`, and never touch `--project`. → Task 9 `test_refuses_existing_output`.

With no clear spot, the trim suggestion is `"end at HH:MM:SS:FF"` (first frame a colliding box appears) or `"start at HH:MM:SS:FF"`, only if ≥ 1.0 s remains; otherwise status `FLAG`.

### Task 6: Project writer

**Interfaces:**
- Consumes: `fb.*`, `Look`, `Placement`, `ProjCue`, `projectio.read_project`.
- Produces: `build_blob(ref: bytes, look: Look, text: str, anchor: int, xoff: float, yoff: float) -> bytes`; `new_hash(n: int) -> str` (`uuid4().hex[:24] + f"{n+12:08x}"` formatted 8-4-4-4-12); `write(project_in: Path, project_out: Path, placements: list[Placement], looks_by_cue: dict[str, Look], ref: bytes) -> None` (`looks_by_cue` is keyed by `ProjCue.block_id`).
